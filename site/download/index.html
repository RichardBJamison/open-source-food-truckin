After it downloads

Two minutes to your first count.

For Mac

  1. Open the zip in Downloads. You get a folder.
  2. Double-click Install.command.
  3. Mac says it can’t verify it? Open System Settings › Privacy & Security, click Open Anyway, then double-click again. START-HERE-MAC.html in the folder shows it step by step.
  4. Asked to install developer tools? Click Install, then run Install.command again.
  5. Your browser opens the program. Bookmark it — that bookmark is the software.

For Windows

  1. Right-click the zip › Extract All. Open the folder.
  2. Double-click Install.bat. “Windows protected your PC”? More info › Run anyway.
  3. No Python yet? It opens python.org. Install it with Add python.exe to PATH checked, then run Install.bat again.
  4. Your browser opens the program. Bookmark it — that bookmark is the software.

It starts by itself when the computer turns on, works offline, and keeps every count on your machine. Updating later: run the new installer — your data stays.
