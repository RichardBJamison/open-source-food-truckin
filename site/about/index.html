The Truck Stop

Built on the asphalt.

Same kitchen that made Open Source Barware. This one just has a parking brake. No founder-chef myth. Operators, a generator, and a program that stays free.

Open Source Food Truckin' exists because the bar program could not pretend a rolling kitchen is a back bar with wheels. Coolers thaw. Festivals change the PAR. The POS is a tablet on the window ledge. The count happens between service and the drive back to the commissary.

We built the sister program in the same house: local-first, GPLv3, English and Spanish, no account, no subscription. Version 1.3-beta is the public toolkit — voice walk, invoice reconcile, daily/weekly/monthly counts, Square/Toast/Clover CSV, plate costing, stop types, load lists, multi-truck, crew PINs.

Find Food Truckin' next to the bar tools at OpenSourceBarware.com. The family also includes Intelligent Hospitality Systems and Reservation Relief.

A Richard B. Jamison project. Free forever.
