## Respaldos {#backups}
Ajustes › Datos. Se guarda un respaldo automático antes de cada borrado o restauración. Presiona **Respaldar ahora** cuando quieras, y **Descargar copia** para guardar una fuera de esta computadora (una memoria USB o tu nube). Tu clave de IA nunca entra en un respaldo.

## Restaurar {#restore}
Sube un respaldo .zip o .json que hayas descargado antes y presiona **Restaurar**. Reemplaza los datos actuales, así que primero se hace un respaldo.

## Datos de ejemplo {#sample-data}
**Cargar camión de tacos de ejemplo** llena este camión con productos y conteos de demostración, todos marcados EJEMPLO. Reemplaza los productos y conteos de este camión (primero se hace un respaldo).

## Borrar datos {#clearing-data}
- **Borrar datos de este camión** quita productos, conteos y registros solo de este camión.
- **Borrar todo** quita todos los camiones, personas y ajustes. Escribe RESET para confirmar.

## Dónde viven los datos {#where-the-data-lives}
Todo está en la carpeta `data` del programa en esta computadora: `store.json`, `config.json` y `photos`. Copia esa carpeta para pasarte a otra computadora.
